Cài game

Game không chơi trên trang web. Cài xong có biểu tượng riêng, mở một chạm, chơi cả khi mất mạng.

Điện thoại AndroidMáy của bạn

  1. Bấm Tải app bên dưới.
  2. Mở file vừa tải, cho phép cài từ nguồn này.
  3. Bấm Cài đặt rồi mở game.
Tải app Android

Không muốn tải file? Mở decheviahe.com/play bằng Chrome, bấm Cài đặt khi game hỏi.

iPhone, iPadMáy của bạn

  1. Mở trang này bằng Safari.
  2. Bấm Mở game bên dưới.
  3. Bấm nút Chia sẻ (ô vuông có mũi tên) → Thêm vào MH chính.
Mở game

Sau đó mở game từ biểu tượng mới trên màn hình chính.

Máy tính WindowsMáy của bạn

  1. Bấm Tải cho Windows.
  2. Mở file vừa tải, bấm Cài đặt.
  3. Mở game từ biểu tượng trên màn hình.
Tải cho Windows

Windows cảnh báo thì bấm More info → Run anyway.

Máy MacMáy của bạn

  1. Bấm Tải cho Mac.
  2. Mở file .dmg, kéo game vào Applications.
  3. Mở game từ Applications.
Tải cho Mac

Máy chặn lần đầu: Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở.
